# Changelog

Notable user-facing changes are recorded here. PixelAid remains under active development.

## 0.2.0 - Robust Preview release candidate

- Added opt-in Robust native reconstruction with Guarded fallback.
- Separated native reconstruction from output-canvas packaging in the editor and CLI.
- Added structured strategy-selection diagnostics across core, worker, automation, HTTP-style, and MCP surfaces.
- Kept Classic as the default and protected unsupported asset workflows.
- Added the Phase 7 acceptance matrix and public Preview documentation.

Full details are in [RELEASE_NOTES.md](RELEASE_NOTES.md).
