# Native-size inference: Step 1G regression foundation

Status: fixture design, pre-improvement characterization, non-regression gates,
and performance coverage complete on local branch `pixel-bench`

Step 1G converts the visual failure classes observed after the sealed Step 1F
evaluation into PixelAid-owned regression fixtures. It deliberately makes no
change to the robust detector or to any product default.

## Product boundary

Robust inference remains available only through the existing explicit core
option:

```ts
grid: {
  detect: "auto",
  autoStrategy: "robust"
}
```

Step 1G does not expose that option through automation, change classic
inference, change asset classification, alter background removal, modify
palette or cleanup behavior, or expand robust eligibility. Manual grids,
explicit target dimensions, and runtime candidates remain authoritative.

The live non-regression suite protects:

- omitted strategy versus explicit `classic`;
- explicit output dimensions over robust candidates;
- the original six-case robust acceptance matrix;
- the five new cases that already satisfy their preregistered contracts;
- the pre-existing product-surface contracts in `robustFix.test.ts` and
  `nativeSizeInference.test.ts`, including background cleanup and excluded
  sheet, tile, portrait, UI, and background paths.

## Corpus ownership and independence

All source art is generated by PixelAid-owned deterministic TypeScript under
`packages/fixtures/src`. The corpus does not copy Retro Diffusion code, Step 1F
art, OpenGameArt art, Kenney art, or pixel-bench distortion outputs.

Six source families represent materially different content geometry:

| Family | Native size | Geometry |
| --- | ---: | --- |
| Tall character | 24x56 | Sparse asymmetric silhouette, narrow limbs, isolated highlights |
| Terrain tile | 32x32 | Dense strata, corners, and repeated short runs |
| UI glyph | 36x36 | Thin ring, diagonal check, broad flat background |
| Micro tile | 8x8 | One-cell accents and high-contrast boundaries |
| Small prop | 24x24 | Transparent outline, diagonal edges, single-pixel detail |
| Flat panel | 48x32 | Wide low-detail color fields and harmonic ambiguity |

The reusable degradation layer provides nearest and bilinear scaling,
low-frequency color fields, channel-opposed chroma noise, ringing, blur,
boundary warp, and cell-local texture, gradient, and noise. The WebP case uses
the existing Apache-2.0 `@jsquash/webp` test dependency for an actual lossy
encode/decode round trip.

## Preregistered acceptance

Each fixture declares its desired behavior before detector work:

1. The authored native dimensions must rank first.
2. Reconstructed pixels are classified against the authored palette to measure
   structural recovery independently of harmless color drift.
3. Transparent sources require a class-specific alpha-mask intersection over
   union.
4. Clean nearest-neighbor input additionally requires exact RGBA reconstruction.

Current failures are characterization data, not assertions that preserve
incorrect behavior. Passing cases are active tests.

## Pre-improvement characterization

The machine-readable baseline is
`packages/core/src/step1g-characterization-baseline.json`. It records the top
five dimensions and confidence, authored-size rank, selected size, and
reconstruction measurements where the selected size is exact.

| Failure class | Role | Native | Current selection | Authored rank | Acceptance |
| --- | --- | ---: | ---: | ---: | --- |
| Color field / tall character | Challenge | 24x56 | 24x28 | absent | Fail |
| WebP / terrain tile | Challenge | 32x32 | 16x16 | absent | Fail |
| Chroma noise / UI glyph | Challenge | 36x36 | 24x24 | absent | Fail |
| Bicubic-like ringing / micro tile | Challenge | 8x8 | 16x16 | absent | Fail |
| Native AA / small prop | Challenge | 24x24 | 24x24 | 1 | Pass |
| Mush warp / tall character | Challenge | 24x56 | 32x77 | absent | Fail |
| Blur / small prop | Challenge | 24x24 | 14x14 | absent | Fail |
| Grid soften / flat panel | Challenge | 48x32 | 24x12 | absent | Fail |
| Clean nearest / tall character | Control | 24x56 | 24x56 | 1 | Pass |
| Cell texture / micro tile | Control | 8x8 | 8x8 | 1 | Pass |
| Cell gradient / terrain tile | Control | 32x32 | 32x32 | 1 | Pass |
| Cell noise / UI glyph | Control | 36x36 | 36x36 | 1 | Pass |

Five of twelve cases pass. All four controls pass. Seven challenges fail, and
the authored size is absent from the returned top five in every failure. That
distinction matters: reranking alone cannot solve these cases.

The native-AA challenge already has strong reconstruction after selecting the
correct size: 99.13% palette-label accuracy, perfect alpha-mask overlap, and a
mean absolute RGBA-channel error of 2.89. The clean nearest control reconstructs
exactly. Cell texture, gradient, and noise all retain perfect palette-label
structure, although harmless within-cell color variations mean exact RGBA
equality is not the appropriate acceptance metric for those classes.

## Performance coverage

The existing six-source robust benchmark now includes the twelve Step 1G
fixtures. The real WebP source is materialized once before measurement, so the
benchmark measures the detector rather than codec startup.

Local result on the development machine:

| Benchmark | Mean | Relative margin of error | Advisory budget |
| --- | ---: | ---: | ---: |
| `robust native-size acceptance matrix: 18 sources` | 84.74 ms | ±0.78% | 125 ms |

The 125 ms budget is advisory while robust inference remains opt-in and until
CI data establishes cross-machine stability.

## Step 1H change protocol

Detector improvements should proceed one general mechanism at a time:

1. Choose one known failure class.
2. Promote its preregistered expectation to a live failing test before changing
   detector code.
3. Diagnose whether the authored axes are missing from axis hypotheses, removed
   during pairing, or lost during reconstruction reranking.
4. Add at least one parameter or source-shape variant so the change cannot pass
   through a single-case constant.
5. Implement the smallest general evidence or scoring change.
6. Require the promoted case, its variant, all five Step 1G passing gates, the
   original six-case matrix, classic/product-surface tests, typecheck, lint,
   build, and the performance budget to pass.
7. Record the new characterization without rewriting the original baseline.

The best first Step 1H target is harmonic under-segmentation. Color field,
WebP, bicubic ringing, and grid softening all select clean divisor/multiple
relationships and can share a general hypothesis-generation investigation.
Warp, blur, and chroma-noise failures should follow because their authored axes
are missing for different evidence reasons.

## Competitive-evaluation status

Step 1F remains an honest historical baseline for the frozen Step 1E
implementation. It is no longer an untouched corpus for a future claim because
its visual failures informed Step 1G. No Step 1F assets or competitor results
are committed to PixelAid.

After Step 1H freezes, any public claim requires a newly sourced and sealed
real-art corpus that is not used for further tuning.
